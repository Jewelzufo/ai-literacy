# ai-literacy

This repository aims to provide basic AI literacy resources to any interested!

All lessons are free, self-paced, and work in the browser, no setup needed. Each page is a single self-contained lesson with practice activities.

## How to Use This Repository

New to AI? Start with the **Start Here** page, which sequences a free course first, then read **AI Safety Basics** and **AI Terms in Plain Terms**, then the **Staying Safe and Thinking Clearly** modules, then work through the **Prompt Template** lessons and the **Prompting Techniques** pages.

## Prompt Engineering

For many, the fastest way to dip their toes in the AI pool is via LLMs and prompting! Prompting is a foundational building block in becoming AI literate!

### Prompt Template 101

A universal reusable prompt template for users of all skill levels!

- [Part 1: The Prompt Template, On One Page](https://jewelzufo.github.io/ai-literacy/) – The four-part template, Context, Role, Goal, Constraints, and why each part helps.
- [Part 2: Practice Activities](https://jewelzufo.github.io/ai-literacy/prompt-template-part-2.html) – Six activities: define your end goal first, then apply the template to each scenario, plus a glossary of key terms.

## Prompting Techniques

- [Part 3: Transforming Data](https://jewelzufo.github.io/ai-literacy/prompt-template-part-3.html) – Turn one kind of data into another with prompts: plain text into GitHub flavored Markdown, a PDF paper into Python code, lists into tables, transcripts into action items, and more.
- [Part 4: Metaprompting](https://jewelzufo.github.io/ai-literacy/prompt-template-part-4-metaprompting.html) – Ask the AI to write and improve your prompts, so you get good results faster: four copy-ready metaprompts, five speed patterns, and five activities.
- [Part 5: Few-Shot Prompting](https://jewelzufo.github.io/ai-literacy/prompt-template-part-5-few-shot.html) – Teach the AI with examples: show 2 to 5 input and output pairs, start with one, add more only when the output misses.
- [Part 6: Chain-of-Thought](https://jewelzufo.github.io/ai-literacy/prompt-template-part-6-chain-of-thought.html) – Ask for the steps, not just the answer, so the reasoning is checkable, with the 2026 caveat for reasoning models.
- [Part 7: Grounding with Your Own Context](https://jewelzufo.github.io/ai-literacy/prompt-template-part-7-grounding.html) – Answer only from a source you provide, quote the lines behind the answer, and say when it is not there.
