Part 4 • Metaprompting

Metaprompting: get the AI to write your prompts

In Parts 1 to 3 you wrote prompts yourself: the template, the end goal, the transformation. In Part 4 you turn the job around. You ask the AI to write and improve the prompt for you, so a good prompt takes one minute instead of ten tries.

Start here

What metaprompting is

A metaprompt is a prompt about a prompt. Instead of asking the AI for the answer, you ask it to write the prompt that will get the answer. You describe the job and what good output looks like, and the AI hands you a finished prompt you can save and reuse.

The slow way“Write a cover letter.” Then five more messages fixing the tone, the length, the missing details, and the wrong format. Each fix costs a round trip.
The fast way“Write me a prompt I can reuse for cover letters. It should ask for the job ad, my experience, and a 250 word limit, in a friendly professional tone.” One metaprompt, one good prompt, reused every time.

Why it makes you faster

  • One round instead of five. The model is good at prompt structure. Let it do the structuring, and you do the judging.
  • Reusable output. A prompt the model wrote for you is a template. Save it, and the next job like it starts at step two.
  • Better first drafts. A metaprompt forces you to state the goal, the format, and the constraints up front, which is the same discipline from Part 1, applied one level up.
  • It teaches you prompting. Reading the prompts the model writes shows you what a complete prompt looks like, so your own prompts get better.

The loop, in four steps

  1. Describe the job in one or two sentences: what you want, and what good output looks like.
  2. Ask for the prompt, not the answer. Use one of the four metaprompts below.
  3. Test it on a real job. Read the output. Judge it against what you asked for.
  4. Refine once, then save it. A prompt that works twice is a template, not a one off.

Four metaprompts that cover most jobs

Each one is ready to paste. Fill in the brackets, send it, and use the prompt it returns as your next message.

1. Improve my prompt

Improve this prompt so it is clear, specific, and complete. Keep my goal the same, add a Role and Constraints where they are missing, and tell me what you changed and why. My prompt: [paste your draft]

2. Write a prompt from a goal

Write me a reusable prompt for this job: [describe the job in one sentence]. Good output looks like: [format, length, tone]. Include Context, Role, Goal, and Constraints sections. Ask me for any detail you need before you finish.

3. Give me three variants

Write three versions of a prompt for this job: [describe the job]. Version 1: short and direct. Version 2: detailed, for a complex case. Version 3: strict, with a checklist the output must pass. Label each version.

4. Critique my prompt

Critique this prompt before I send it. Score it out of 10 for clarity, specificity, and completeness. List exactly what is vague or missing, then rewrite it with those gaps fixed. My prompt: [paste your draft]

Rule of thumb: metaprompt 2 is the default. Use 1 when you already have a draft, 3 when you are unsure which approach fits, and 4 when a prompt keeps failing and you cannot see why.

Speed patterns

Five patterns that save the most time

Build a prompt librarySave every prompt that works twice. A text file with five good prompts beats rewriting from scratch every time.
Ask for the template, not the answerWhen a job repeats, ask for a prompt with blanks, like [topic] and [length], instead of one finished answer.
Batch the same jobOne good prompt, run on five inputs in a row, is faster than five improvised prompts.
Constraints firstState format, length, and tone in the metaprompt. The generated prompt inherits them, so you do not retype them each time.
One fix per roundWhen a generated prompt fails, change one thing and test again. Changing three things at once hides which fix worked.

Before you trust it

Speed checklist, for every metaprompt

  • Did I describe the job in one sentence, and say what good output looks like?
  • Did I ask for a prompt, not the answer? If I got an answer instead, I asked the wrong question.
  • Did I test the generated prompt on a real job before saving it?
  • Did I fix one thing at a time when it failed, instead of rewriting everything?
  • Did I save the prompt that worked, with a one line note about what it is for?
  • Am I reusing more than I am rewriting? If every job still starts from a blank box, the library is not earning its keep.

Remember: a metaprompt is a shortcut to a good prompt, not a shortcut past thinking. You still judge the output, and you still own the result.

Common failure modes

  • Vague metaprompt: “Write me a good prompt.” The model cannot guess the job. Fix: one sentence for the job, one for good output.
  • Endless refinement: polishing the prompt for longer than the job would take. Fix: two rounds maximum, then test it on the real job.
  • Trusting the generated prompt blindly: it may add steps, tools, or claims you never asked for. Fix: read it once, cut what does not belong, then test.
  • No library: every good prompt is lost in chat history. Fix: one text file, one line per prompt, updated the day it works.

Reference

Glossary: metaprompting terms

Short, plain definitions for the new terms used on this page. The Part 2 glossary covers Context, Role, Goal, and Constraints.

Metaprompt
A prompt that asks the AI to write or improve a prompt, instead of asking for the answer directly.
Metaprompting
The practice of using metaprompts to create, test, and refine prompts faster.
Prompt library
A saved collection of prompts that work, kept in one place so they can be reused.
Variant
One of several versions of a prompt for the same job, made to compare approaches.
Critique
A review that scores a prompt and lists exactly what is vague, missing, or wrong.
Iteration
One round of testing a prompt, seeing the result, and changing one thing.
Round trip
One message to the AI and one reply back. Fewer round trips means a faster job.
Reusable prompt
A prompt written with blanks, like [topic] or [length], so it works for many jobs of the same kind.
Template
A fixed prompt structure with blanks to fill in, kept the same across jobs.
First draft
The first version of a prompt or an output, made to be tested and improved, not trusted as final.
Edge case
An unusual input, such as an empty list or a missing date, that a prompt must still handle correctly.
Blind trust
Using a generated prompt or output without reading and checking it first.
